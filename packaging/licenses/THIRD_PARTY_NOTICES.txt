About the LGPL components (Qt, PySide6, LibRaw, FFmpeg)
  - They are used unmodified and as separate shared libraries (.dll on
    Windows; .dylib / .framework inside Film Converter.app on macOS), so you
    may replace them with your own compatible builds.
  - Their complete source code is available from the projects:
      Qt 6.12.0 ............ https://download.qt.io/official_releases/qt/6.12/
      PySide6 6.12.0 ....... https://download.qt.io/official_releases/QtForPython/
      LibRaw ............... https://www.libraw.org/download
      FFmpeg ............... https://ffmpeg.org/download.html
                             (build used by OpenCV: https://github.com/opencv/opencv-python)
  - If any of these links stop working, ask through the project page and
    we will provide the corresponding source code.

The GPL-only Qt module "Qt Virtual Keyboard" is deliberately not included.
LibRaw is used without its optional GPL demosaic packs.

Film Converter's own code and icon are original work. It does not contain
code, presets or artwork from any other film-conversion product.
